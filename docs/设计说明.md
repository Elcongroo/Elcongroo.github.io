# 排版与内容层次

网站采用技术札记的阅读方式。主页只出现一份文章列表，不重复精选、推荐和目录。作者与主题位于次要侧栏，手机上移到文章列表之后。

每篇条目依次呈现标题、摘要、要点、依据、验证边界和正文入口。标题直接写明技术对象与问题；摘要概括方法与范围；要点由正文中的证据或资料支持。公开资料阅读与实际实验分开标注。学术风格不代表论文发表、同行评审或专家身份。

英文优先使用 Times New Roman，缺失时回退到 Times、Liberation Serif 和衬线字体。中文使用自托管 Noto Serif SC，代码使用 JetBrains Mono。正文采用左对齐、适当行距，避免强制两端对齐产生字距空洞。深色模式保持同一结构。

文章页开头呈现作者、日期、摘要、要点和依据。技术环境可展开；正文章节编号，保留静态图示、代码、原始材料、更新记录与目录。

历史版本曾参考 https://www.hejustinsun.com/zh/insights 的精选版面和蓝色页脚。它对本站造成了内容重复和视觉注意力分散，本版删除这些结构，保留清晰导航。首页样式在 src/styles/home.css，共用的文章摘要组件在 src/components/PostRow.astro，正文与全局字体在 src/styles/global.css。
