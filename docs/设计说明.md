# 版式说明

参考：https://www.hejustinsun.com/zh/insights

采用的组织方法：独立署名与居中导航、具有视觉重点的精选内容、人物介绍与密集目录并列、蓝色页脚收束。

博客的处理：精选区域缩小为一篇文章与三篇近期笔记并排，避免大幅内容独占桌面首屏。图示来自 TCP 受控实验的既有记录：首次正文读取 8/16 字节。这不是 TCP 固定分段规律。没有使用参考站的照片、标志、文案、视频或代码。

正文保留 Noto Serif SC；英文署名使用 Newsreader；源码、日期和协议字段使用 JetBrains Mono。主强调色为蓝色，精选与页脚使用实色深蓝。文章正文宽度与证据结构保持稳定。

首页样式在 src/styles/home.css，全站导航、页脚与阅读样式在 src/styles/global.css。文章目录、标签和归档由内容集合生成；精选实验图示与个人简介在首页源码手动维护。更换精选文章时，需要同时调整图示和说明，不能把旧实验数据移植给新文章。

手机先展示精选文章与近期笔记，随后是完整目录；作者简介移到目录后。全文搜索按需加载，关闭 JavaScript 不影响文章与图示阅读。
