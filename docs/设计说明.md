# 设计与阅读规则

## 当前方向：有编辑层次的个人技术博客

浅色页面保持纯白。文章标题使用接近纯黑的重字重，正文为深灰，时间、来源与说明为中灰；分隔线再浅一级。依靠明暗、大小和版面比例区分信息，栏目和文章标题不统一染成强调色。

- 标题：#111111；正文：#292929；辅助文字：#737373；页面：#ffffff。
- 朱红用于当前导航下划线、署名句点和最近更新标记。
- 绿色表示经过实验验证或正常收齐；橙色表示待验证、提前 EOF 与未收齐的路径。均有文字说明，不依赖颜色单独传达状态。
- 实验读取对照使用深墨绿色底，只有这一块证据采用反白排版，不把文章包装为统一卡片。

中文沿用自托管 Noto Serif SC，但加大标题与正文的字重差别。英文正文优先 Times New Roman，回退 Times / Liberation Serif；源码、日期与读取记录使用 JetBrains Mono。衬线字体只是一种阅读选择，不代表论文发表、同行评审或专家身份。

## 首页

首篇文章有更大的黑色标题、摘要、要点和明确的阅读入口。当前重点为高性能网络的测量方法，配套图解只呈现测量对象，不伪造图表数据。最新文章用细边框、单个圆弧转角和错位角标强调；悬停及键盘聚焦时角标轻微移动，减少动态效果偏好下保持静止。

其余内容分成连续阅读主线与旁支实验。主线以分类／回溯坐标边栏和标题／摘要主栏组成紧凑索引。每篇在首页只出现一次。作者介绍、分类、主线入口和实验疑问放在右侧；手机上放到文章之后。

TCP 文章的读取对照由 src/components/StreamEvidence.astro 在构建时直接导入 public/downloads/tcp-stream-lab/evidence/run-03.json。显示的请求长度、返回长度与累计进度均由记录计算；不是新的实验，不是重建的终端截图，也不表示 TCP 分段。正常用例为两次正文读取各 8 字节；提前 EOF 用例为 8 字节后返回 0，并成功检测残缺。这个负向用例不是回归失败。Codex 执行和作者本人复现尚未完成的边界仍紧邻文章。

StreamEvidence 仅供 TCP 文章精选时使用。当前 PerformanceMap 只供性能画像文章使用，所有指标均为待测项目。后续文章不会自动套用这两块内容。没有图示时直接显示文字，不生成虚假素材补齐版式。

## 参考与取舍

- [Bartosz Ciechanowski](https://ciechanow.ski/)：技术图解与正文共同解释问题。本站借鉴“让内容本身形成视觉重点”的方法，不复制其模型或引入无关动画。
- [Julia Evans](https://jvns.ca/)：保留明确的文章与主题入口。
- [Tufte CSS](https://edwardtufte.github.io/tufte-css/)：正文与补充材料分层，相关图表紧邻其说明。
- [读者对博客阅读体验的讨论](https://news.ycombinator.com/item?id=48466488)：用于找参考与检查阅读问题，不当作设计排行榜或所有读者的共识。

上一版的主要问题是蓝色被用于过多无关层级、灰度接近，以及每篇文章都重复相同摘要表单。这一版取消那些用法，而不是把蓝色整体替换成另一种颜色。

## 去模板化与维护

没有营销 Hero、装饰性数字、背景网格、技术 Logo 墙、虚构项目或自动封面。首页的特别排版由真实内容决定；源码、协议图和性能数据只有在文章真的提供它们时才呈现。

标题、摘要、证据、验证边界保持独立字段。首页紧凑文章不重复展示全部要点；完整元数据在文章目录与正文页保留。正文宽度、目录、代码与图示的移动端滚动不因首页排版改变。

入口：src/pages/index.astro；首页：src/styles/home.css；共用文字和颜色：src/styles/global.css；普通文章条目：src/components/PostRow.astro；连续阅读：src/pages/journey.astro。内容方向与回溯日期见 docs/内容主线与日期规则.md。
