# 排版与内容层次

浅色模式使用纯白背景（#ffffff）。以蓝色署名、文章标题的大小差别和主栏／边栏的比例保留个人风格。首页是一份连续文章列表，首篇稍突出，不重复精选、推荐和目录，也不使用大面积海报、数字图形和统一卡片。

## 参考与取舍

2026-09-29 对照了以下页面。读者讨论用于寻找参考，并不能证明存在所有人认可的最佳设计；最终取舍以本站的中文技术文章为准。

- [Hacker News：阅读体验好的文字博客](https://news.ycombinator.com/item?id=48466488)：讨论涉及字体、行宽、代码阅读和对正文的干扰。以此作为阅读检查清单，不当作权威排行榜。
- [Julia Evans](https://jvns.ca/)：借鉴最近文章和按主题查找的明确入口。本站只展示已有内容的主题，不借用她的视觉装饰、文章或个人形象。
- [Josh W. Comeau](https://www.joshwcomeau.com/)：借鉴文章标题、足够具体的摘要和辅助侧栏之间的层次。不引入云朵背景、人物模型和额外动画。
- [Tufte CSS](https://edwardtufte.github.io/tufte-css/)：借鉴正文与补充材料分层、图文紧邻的原则。保留中文宋体与现有侧栏目录，背景按作者要求使用纯白，不直接采用其米白配色。
- [Nikita Prokopov](https://tonsky.me/)：清楚的年度索引值得参考，但本站只有四篇文章，现阶段直接展示摘要比复杂年份导航更实用。

## 本站的具体安排

首页首篇标题较大、采用蓝色；其余文章保持紧凑的标题、摘要、要点、依据与验证边界。首篇仍在同一文章序列中，每篇仅出现一次。所有颜色与状态以文字配合表达，不能只靠颜色传达含义。分类名称可直接点击。

右栏保留简短的第一人称自我介绍、真实文章分类数量、最新实验手记和其中未解决的问题。实验状态来自内容集合，不生成新的实验事实。手机上正文先行，辅助栏目移至文章之后。

英文正文优先使用 Times New Roman，缺失时回退到 Times、Liberation Serif 和衬线字体。中文使用自托管 Noto Serif SC，代码使用 JetBrains Mono。署名使用斜体。正文左对齐，避免强制两端对齐导致字距空洞。保留深色模式。

文章页开头呈现作者、日期、摘要、要点和依据。技术环境可展开；正文章节编号，保留静态图示、代码、原始材料、更新记录与目录。学术排版不代表论文发表、同行评审或专家身份。

## 去模板化检查

- 没有 SaaS 式首屏：第一屏直接进入文章，不展示产品口号、客户数字和购买按钮。
- 可套用的文字限制在导航和说明；文章标题、要点和实验疑问明确指向 Socket、TUN、IPsec 和密码协议。
- 蓝色横线分隔文章栏，细线划分旁注；不加入无含义的网格、编号、终端外壳和封面。
- 首篇与后续文章有大小差别，侧栏按实际内容长短排布，不强制等高。
- 作者的方向由真实技术问题体现；去掉名字，仍能看出这是一份围绕 VPN 和密码网关的个人笔记，但不虚称已有独一无二的内容品牌。
