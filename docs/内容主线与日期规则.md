# 技术框架与原文选刊

博客以 congroo 的技术思考与源码解读为主体。`/journey/` 是《高性能安全通信系统栈》的技术导航，不再承载个人经历或编排的时间线。

## 框架

保留原图 01–13 的技术模块，以及 PQC 迁移、特殊网络场景、编程工具、调试与工程工具链四条横向线索。网页在 `src/data/system-stack.ts` 维护模块范围和文章 ID。框架线条表示主题层次，不是严格报文执行顺序。

只公开技术部分。公司名称、内部目标、职业晋升、薪酬与原图的示意性能数字不作为博客内容。没有文章的模块明确标为未选刊。

## 原文选刊

七篇选刊由 `scripts/import-reviewed-notes.py` 从明确指定的原稿目录导入。脚本不遍历整个私有库，也不自动发布后来增加的稿件。

- 保持原文技术正文、章节顺序、代码与 Mermaid 图。
- 去掉重复 H1 和原库阅读统计；在文章元数据中提供标题与阅读时间。
- MkDocs 提示语法改成 Markdown 引用块，保留文字。
- 相互引用的已选刊文章映射为博客地址；未选刊的引用保留标题并注明状态。
- 性能文章本次不选刊第 11 节原仓库配套脚本，文章上方明确说明。
- `src/data/publication-sources.json` 记录原文版本、原文与选刊正文的 SHA-256。维护时可运行导入脚本的 `--check`，核对网页源稿与原库是否一致。

以前独立改写的入职叙事、KEM 概览和验证方法稿已撤下。旧地址跳转到相关源码文章或技术框架，避免失效。

## 日期

`date` 为首次实际公开日期；`updated` 为真实修订日期。RSS 和结构化数据使用这些日期。不再提供 `journey.date` 或虚构的阅读坐标，不为了视觉分布而改变历史。

## 验证边界

选刊本身不是重新执行实验。strongSwan / OpenVPN 文章标为源码分析，Linux 笔记标为公开资料。原 TCP 示例实验及证据保留，不改动它的执行者或日期。
